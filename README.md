# qt-qml

Проект демонстрирует управление устройством FTDI FT4222 через Qt Quick.

## Требования
- Qt 6.9+ с компонентами `Quick` и `SerialPort`
- Компилятор MSVC 2022 (x64)
- Драйверы и SDK FTDI (`FTD2XX`, `LibFT4222`) — временно хранятся в каталоге `libs/`

## Сборка
```powershell
cmake -S . -B build -G "Ninja Multi-Config"
cmake --build build --config Debug
```

Для переноса на другую машину переопределите пути к SDK:
```powershell
cmake -S . -B build `
  -DFTD2XX_ROOT="C:/path/to/ftd2xx" `
  -DFT4222_ROOT="C:/path/to/LibFT4222"
```

Утилита `windeployqt` запускается автоматически после сборки (берётся из переменных `QTDIR`, `Qt6_DIR`, `Qt6_ROOT`).

## Запуск
1. Подключите FT4222-совместимое устройство.
2. Запустите `appqt-qml.exe` из каталога сборки (`build/Debug` по умолчанию).
3. В интерфейсе:
   - `Connect` сканирует USB и инициализирует первое найденное устройство.
   - `Scan I2C Bus` обновляет список устройств и выводит информацию в лог.
   - Укажите адрес ведомого (например, `0x2A`) и ширину регистра (1 или 2 байта) перед чтением/записью.

## Структура
- `src/` — C++-код: обёртка FT4222, менеджер последовательного порта.
- `qml/` — QML-интерфейс.
- `libs/` — локальные копии SDK FTDI (в продакшене лучше подключать через пакетный менеджер).
